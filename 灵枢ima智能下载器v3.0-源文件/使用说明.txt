                            灵枢IMA智能下载器 V3.0
                                  使用说明
                            作者：灵枢
                       ========================================


  【快速开始】

    1. 双击 灵枢ima智能下载器.exe 启动程序（推荐）或 start.bat 启动
    2. 启动后自动加载首页推荐知识库列表
    3. 在搜索框输入关键词（如"医保""教程"）按回车搜索
    4. 双击感兴趣的知识库卡片，自动浏览文件列表
    5. 点击"开始批量下载"按钮即可下载
    6. 下载文件保存在 downloads/知识库名称_ID/ 目录


  【四大功能标签】

    发现页
      首页推荐知识库 + 关键词搜索 + 知识库卡片展示
      支持搜索历史记录（点击"历史"按钮查看）
      支持收藏夹（右键知识库卡片选择收藏，数据持久保存）
      刷新按钮重新加载首页推荐列表

    浏览
      文件列表详情展示（文件名、大小、类型、更新时间）
      不同文件类型用不同颜色标识（PDF红色、Word蓝色、Excel绿色等）
      支持逐层深入子文件夹（最多10层）
      右键菜单：预览文件、下载当前文件夹全部文件
      面包屑路径显示当前位置，支持返回上级文件夹

    下载管理
      粘贴知识库ID（纯数字）或分享链接进行下载
      实时显示下载速度、剩余时间、每项文件下载进度
      支持断点续传（中断后重新下载可从断点继续）
      支持失败重试、下载队列管理
      可导出下载清单

    批量下载
      从浏览页点击"下载全部"触发
      显示文件列表、单项下载进度、批量总进度百分比


  【推荐操作流程】

    方式一（最推荐）
      发现页搜索 → 双击知识库卡片 → 浏览文件 → 点击"开始批量下载"

    方式二
      发现页搜索 → 右键知识库卡片 → 选择"批量下载"

    方式三
      下载管理页 → 粘贴知识库ID（纯数字） → 点击"开始下载"
      系统自动查询知识库名称，文件夹命名为"知识库原名_ID"

    方式四
      下载管理页 → 粘贴分享链接 → 点击"开始下载"


  【ID类型说明】

    知识库ID（推荐）
      纯数字格式，10~25位（如 7307200439519008）
      无需登录即可使用，系统自动获取知识库名称

    分享链接
      格式示例：https://xxx.xxx/s/xxxxx
      程序自动提取分享ID后进行下载

    分享ID
      十六进制字符串
      需要登录态支持，当前版本暂不可用


  【右键菜单】

    发现页知识库卡片右键
      浏览知识库 — 在浏览Tab中查看文件列表
      批量下载 — 直接下载该知识库所有文件
      复制知识库ID — 复制到剪贴板
      收藏/取消收藏 — 加入收藏夹，下次快速访问

    浏览页文件列表右键
      预览文件 — 预览图片、PDF、文本等格式
      下载当前文件夹 — 下载当前文件夹下所有文件（文件夹右键时）


  【V3.0 新增功能】

    1. 下载速度实时显示与剩余时间估算
    2. 下载队列管理与失败自动重试
    3. 断点续传 — 中断后重新下载可从断点继续，节省时间
    4. 知识库收藏夹 — 右键收藏，数据本地持久保存
    5. 搜索历史记录 — 点击"历史"按钮查看近期搜索
    6. 文件预览 — 右键文件选择预览（图片/PDF/文本等）
    7. 导出下载清单 — 下载完成后可导出文件列表
    8. 代理设置 — 支持HTTP/HTTPS/SOCKS代理配置


  【文件类型颜色标识】

    PDF文档    红色标签      Word文档    蓝色标签
    Excel表格  绿色标签      PPT演示     橙色标签
    图片文件    紫色标签      视频文件    粉色标签
    音频文件    黄色标签      压缩包      棕色标签
    代码文件    青色标签      其他文件    蓝色标签
    文件夹      棕色边框


  【文件夹浏览】

    - 双击文件夹可进入子文件夹浏览
    - 最多支持10层子文件夹递归浏览
    - 面包屑路径显示当前位置
    - 点击面包屑可返回上级文件夹
    - 点击"开始批量下载"下载当前显示的所有文件


  【配置说明】

    下载路径
      默认为程序目录下的 downloads/ 文件夹
      可在 config/app.properties 中修改 download.dir

    并发线程
      默认20个线程同时下载
      可修改 download.thread 调整（建议10~30）

    重试次数
      默认失败后重试2次
      可修改 download.retry.count

    代理设置
      支持HTTP、HTTPS、SOCKS代理
      可在设置菜单中配置，或在 config/app.properties 中修改
      proxy.type: none / http / socks
      proxy.host: 代理服务器地址
      proxy.port: 代理端口

    日志文件
      每天自动生成一个日志文件，保存在 logs/ 目录
      文件名格式: 2026-07-08.log
      记录所有操作详情，便于排查问题
