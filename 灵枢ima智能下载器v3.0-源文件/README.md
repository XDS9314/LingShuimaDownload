## 主要功能

### 1. 发现页（Tab 1）

- **首页推荐**：启动自动加载热门和推荐知识库，卡片式展示
- **关键词搜索**：输入关键词回车搜索，支持清空关键词回到首页推荐
- **知识库卡片**：封面缩略图 + 标题 + 发布者 + 简介 + 文件数/成员数/分享数/点赞数 + 更新时间
- **双击浏览**：双击知识库卡片，自动获取知识库全部文件列表并跳转到批量下载页
- **右键菜单**：浏览知识库 / 批量下载 / 复制知识库ID

### 2. 下载管理（Tab 2）

- **多种输入支持**：知识库ID / 分享ID / 分享链接（每行一个）
- **智能识别**：自动判断输入类型，知识库ID走批量下载流程，分享ID走单文件下载流程
- **实时进度**：总进度条 + 当前文件进度条 + 统计信息
- **文件表格**：序号、类型、文件名、大小、状态
- **日志记录**：带时间戳的详细日志，支持自动滚动和行数限制
- **快捷操作**：粘贴 / 开始下载 / 停止 / 打开文件夹 / 清空日志 / 极速模式

### 3. 批量下载（Tab 3）

- **文件列表**：彩色图标 + 文件名 + 类型Badge + 下载状态（绿色可下载/红色无链接） + 路径
- **文件夹标识**：黄色圆角图标 + "文件夹"Badge + 双击可进入浏览子文件夹
- **批量下载**：一键下载当前知识库全部可下载文件，自动以知识库名称创建文件夹
- **子文件夹浏览**：双击文件夹可递归浏览，右键也可操作
- **进度显示**：渐变色圆角进度条 + 文件数量统计
- **下载日志**：带时间戳的实时日志

## 使用方法

### 启动程序

```
双击 start.bat
```

### 方式一：发现页浏览下载（推荐）

1. 启动后自动加载首页推荐知识库
2. 搜索框输入关键词（如"医保"）后按回车搜索
3. 浏览搜索结果，找到目标知识库
4. **双击**知识库卡片 → 自动浏览文件列表
5. 查看文件列表后，点击 **"开始批量下载"**
6. 等待下载完成，文件保存在 `downloads/知识库名称/` 目录

### 方式二：右键菜单下载

1. 在发现页找到目标知识库
2. **右键**点击知识库卡片
3. 选择"批量下载" → 确认后自动跳转批量下载页并开始

### 方式三：手动粘贴ID下载

1. 在发现页右键 → "复制知识库ID"
2. 切换到 **下载管理** 标签页
3. 粘贴知识库ID（纯数字，10-25位）到输入框
4. 点击"开始下载"

### 浏览子文件夹

1. 在批量下载页的文件列表中，**双击文件夹**图标
2. 自动加载子文件夹内容
3. 可继续双击更深层的文件夹
4. 点击"开始批量下载"下载当前列表中的所有文件

## ID类型说明

| 类型 | 格式 | 来源 | 用途 |
|------|------|------|------|
| **知识库ID** | 纯数字（如 `7436595691020395`） | 搜索/首页推荐 | 获取整个知识库全部文件，批量下载 |
| **分享ID** | 64位十六进制（如 `a1b2c3d4...`） | 文件分享功能 | 下载单个分享文件（需Cookie） |
| **分享链接** | `https://ima.qq.com/s/xxxxx` | 别人分享的链接 | 软件自动提取其中的分享ID |

> **注意**：分享ID/链接走旧版分享API，需要登录态Cookie，当前不支持登录，推荐使用知识库ID方式。

## 常见问题

### Q: 首页推荐加载失败？
- 检查网络连接是否正常
- 查看日志中的错误信息
- 重启软件重试

### Q: 搜索没有结果？
- 尝试更换关键词（如"教程""文档"等通用词）
- 确认网络连通性
- 部分冷门关键词可能确实没有对应知识库

### Q: 批量下载没有反应？
- 确认已通过双击或右键浏览了知识库（需要先加载文件列表）
- 检查"开始批量下载"按钮是否可点击（灰色=未加载列表）
- 如果文件全部显示"无下载链接"，说明该知识库文件未公开下载权限

### Q: 下载的文件夹名字不对？
- V3.0已修复，文件夹名称使用知识库真实名称
- 如果从下载管理Tab手动粘贴知识库ID，且该知识库已在前序操作中浏览过，会自动匹配名称
- 全新粘贴的纯数字ID会使用"知识库_ID"格式

### Q: 文件名出现乱码或特殊符号？
- V3.0已优化文件名清洗逻辑，自动去除HTML标签和非法字符
- 保留空格，去除 `# % & *` 等文件系统非法字符

### Q: 图标设置报错 ICON_IMAGE？
- V3.0已修复，增加了平台兼容性检查（`Taskbar.isTaskbarSupported()`）
- 该错误不影响软件功能使用

### Q: 右键菜单不弹出？
- 需要在列表项上右键点击（空白区域无效）
- 不同操作系统右键触发方式不同（Windows：右键松开时触发）
- 尝试右键按下后松开触发

### Q: Java版本要求？
- 推荐 Java 11+
- 最低 Java 8
- 运行 `java -version` 查看当前版本
