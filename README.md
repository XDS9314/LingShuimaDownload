## 简介

灵枢 IMA 智能下载器是一款腾讯 IMA 知识库的搜索、浏览与批量下载工具。无需登录即可发现、搜索和下载公开知识库中的文件，支持文件夹递归浏览、批量下载、文件类型识别等功能。

## 核心功能

### 发现页

- **首页推荐** — 启动自动加载热门知识库，卡片式展示（封面 + 标题 + 发布者 + 简介 + 统计）
- **关键词搜索** — 输入关键词即时搜索，支持清空回到首页推荐
- **右键菜单** — 浏览知识库 / 批量下载 / 复制知识库 ID
- **双击浏览** — 双击卡片自动加载文件列表

### 下载管理

- **多格式输入** — 支持知识库 ID / 分享 ID / 分享链接
- **智能识别** — 自动判断输入类型，匹配对应下载流程
- **实时进度** — 总进度条 + 单文件进度条 + 速度统计
- **极速模式** — 多线程并发下载，可配置线程数

### 批量下载

- **文件列表** — 彩色类型图标 + 文件名 + 大小 + 下载状态
- **递归浏览** — 双击文件夹逐层进入，最多 10 层
- **一键下载** — 自动以知识库名称创建文件夹，批量保存

## 使用指南

### 推荐流程

```
搜索关键词 → 双击知识库卡片 → 浏览文件列表 → 点击"开始批量下载"
```

### ID 类型说明

| 类型 | 格式 | 是否需要登录 | 说明 |
|------|------|:---:|------|
| 知识库 ID | 纯数字（10-25 位） | 否 | 获取整个知识库文件列表，批量下载 |
| 分享链接 | `https://ima.**.com/s/xxxxx` | 是 | 自动提取分享 ID 下载单文件 |
| 分享 ID | 64 位十六进制 | 是 | 需登录态 Cookie，当前版本暂不可用 |

### 文件类型标识

| 类型 | 颜色 | 类型 | 颜色 |
|------|------|------|------|
| PDF | 红色 | Word | 蓝色 |
| Excel | 绿色 | PPT | 橙色 |
| 图片 | 紫色 | 视频 | 粉色 |
| 音频 | 黄色 | 压缩包 | 棕色 |
| 代码 | 青色 | 文件夹 | 棕色边框 |
```

## 常见问题

<details>
<summary>点击展开 FAQ</summary>

**Q: 首页推荐加载失败？**
检查网络连接，确认能访问 `ima.qq.com`，重启软件重试。

**Q: 搜索没有结果？**
尝试更换关键词（如"教程""文档"等通用词），部分冷门关键词可能确实没有对应知识库。

**Q: 批量下载没有反应？**
需要先双击或右键浏览知识库（加载文件列表），然后点击"开始批量下载"。

**Q: 文件名出现乱码？**
V3.0 已优化文件名清洗逻辑，自动去除 HTML 标签和非法字符。如仍有问题请提交 Issue。

**Q: 图标设置报错？**
V3.0 已增加平台兼容性检查，不影响软件功能。
